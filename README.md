# Entrega do FPS Lab

Esta branch serve somente para baixar o ZIP de um projeto Git independente.
A main e a branch do Zombie Outbreak não foram alteradas.

Baixe `zombie-outbreak-fps-lab.zip` pelo botão **Download raw file** do GitHub.
O arquivo inclui o repositório `.git`, fontes do Evostrike, licenças e o build
de inspeção. Ainda faltam os assets para torná-lo jogável.

SHA-256: `e8409b47ffad034547b2d0e37715a4a769615af54da975edd64653c548ebae3b`

1. Extraia o ZIP em outra pasta.
2. GitHub Desktop: File > Add local repository > selecione zombie-outbreak-fps-lab.
3. Publish repository > zombie-outbreak-fps-lab > Keep this code private.
4. Selecione o novo repositório no Codex para continuar nele.

O README dentro do ZIP contém os detalhes. `ABRIR_FPS_LAB.cmd` abre somente
o laboratório de inspeção, sem ativar os controladores FPS incompletos.
